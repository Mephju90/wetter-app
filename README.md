# Wetter-App 🌦️

Eine kleine Wetter-App mit HTML, CSS und JavaScript.  
Sie nutzt die [OpenWeatherMap API](https://openweathermap.org/api), um aktuelle Wetterdaten anzuzeigen.

🔗 **Live-Demo:** 

## ⚙️ Funktionen

- Stadt eingeben und Wetter abrufen
- Temperatur, Wetterlage und Windgeschwindigkeit anzeigen
- Fehlerbehandlung bei ungültigen Eingaben

## 🛠 Verwendete Technologien

- HTML5
- CSS3
- JavaScript (fetch, async/await)
- OpenWeatherMap API
- GitHub Pages (für Hosting)
